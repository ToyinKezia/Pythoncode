## Projects

### Machine Learning
**Predicting US Wheat Farm Price**
Developed and compared three machine learning models — Random Forest, 
XGBoost and Linear Regression — to predict US wheat farm prices. 
Includes feature engineering, model training, and evaluation metrics 
(RMSE, R²), and comparative performance analysis.

**US Cereal Production Forecasting (Prophet)**
Applied Meta's Prophet library to forecast US cereal production trends 
using time series modeling. Includes seasonality decomposition and 
forward projections.

### Data Retrieval & APIs
**Calling Data from the World Bank API**
Demonstrated programmatic data retrieval from the World Bank Open Data 
API using Python's requests library. Includes data parsing, 
transformation, and export for downstream analysis.

### Data Cleaning & Analysis
**Cleaning Food Security Data**
Applied data cleaning techniques to a food security dataset, including 
handling missing values, standardizing formats, removing duplicates, 
and preparing data for analysis.

**Calculating Confidence Intervals**
Statistical analysis demonstrating confidence interval calculation 
across datasets using NumPy and SciPy.

**Correlation and T-Test Analysis**
Applied correlation analysis and independent samples t-tests to 
explore relationships between variables in development-relevant datasets.

**Z-Score Analysis**
Outlier detection and normalization using the z-score methodology.
